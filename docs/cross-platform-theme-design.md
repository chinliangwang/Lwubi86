# Rime 跨平台主题配色设计

## 设计理念

基于 Windows 11 系统默认输入法风格，打造现代、简约、跨平台的 Rime 输入法主题配色方案。

### 核心原则

- **系统化设计**：完全遵循 Windows 11 Fluent Design 规范
- **平台适配**：根据各平台特性调整布局和细节
- **现代简约**：遵循各平台的现代设计语言
- **高对比度**：确保可读性和可访问性
- **一致性**：保持跨平台视觉一致性

## Windows 11 配色方案

### 设计特点

- **Fluent Design**：圆角、柔和阴影、清晰层次
- **系统化配色**：完全遵循 Windows 11 系统默认输入法风格
- **Windows 蓝色**：#0078D4 作为选中背景，符合系统规范
- **简洁现代**：去除所有花哨颜色，使用系统默认色板

## 实施指南

### Windows 11

1. 修改 `weasel.custom.yaml`
2. 部署配置：`右键托盘图标 → 重新部署`
3. 验证效果：输入测试，观察配色和布局

### macOS

1. 修改 `squirrel.custom.yaml`
2. 部署配置：`菜单栏 → 重新部署`
3. 验证效果：输入测试，观察配色和布局

### Linux (IBus/Fcitx)

1. 修改 `ibus.custom.yaml` 或 `fcitx.custom.yaml`
2. 部署配置：重启输入法
3. 验证效果：输入测试，观察配色和布局
