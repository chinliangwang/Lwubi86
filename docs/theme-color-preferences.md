# 主题配色需求与偏好

## 核心风格

- **参考系**：Dracula 官方色卡
- **目标风格**：现代简约 + Windows 11 风格
- **主题数量**：亮色 + 暗色双主题

---

## 配色原则

| 元素 | 偏好 | 说明 |
|------|------|------|
| 编码提示 | 柔和不抢眼 | 避免与选中字竞争注意力 |
| 编号颜色 | 清晰醒目 | 一眼可辨 |
| 选中背景 | 舒适不刺眼 | 避免过高饱和度 |
| 整体风格 | 高对比度、色彩丰富 | 保留 Dracula 特色 |

---

## 布局偏好

- 贴近系统输入法布局（margin_x: 14, candidate_spacing: 10）
